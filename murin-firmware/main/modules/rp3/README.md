### PR3 Flash new firmware
- Open ELRS configurator
- Select target
  - Device category: RadioMaster 2.4 GHz
  - Device: RadioMaster RP3 Diversity 2.4GHz RX
- Flashing Method: UART
- Device Options:
  - 2.4 GHz ISM (Standard)
  - Set loacl wifi name and passwod
  - Set Phrase
- Action
  - Manual: choose COM port
- Keep rp3 off, hold boot button, power on, led becomes solid red then release the button
- Flash

#### Radiomaster Pocket flash firmware
- Open ELRS configurator
- Select target
  - Device category: RadioMaster 2.4 GHz
  - Device: RadioMaster Pocket Internal 2.4GHz TX
- Flashing Method: WIFI
- Device Options:
  - 2.4 GHz ISM (Standard)
  - Set loacl wifi name and passwod
  - Set Phrase
